### 의존성 관리 전략

1. **강한 의존성** (Synchronous Call)
   - User Preference → Auth Service (사용자 정보 조회)
   - Community → Housing Service (주택 정보 조회)

2. **약한 의존성** (Event-Driven)
   - Auth Service → Notification Service (회원 가입 → 이메일 발송)
   - Housing Service → Analytics Service (조회 수 업데이트)

3. **캐싱 전략**
   - User Preference Service에 User 기본 정보 캐싱
   - Redis 활용 (추후 도입)
